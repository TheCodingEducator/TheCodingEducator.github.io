Teaching Notes for Educators

Tip the Scales covers the full linear-equations unit on one literal balance scale - from isolating a variable in a single step, through two-step equations, to collecting variables on both sides and distributing across parentheses. The same visual metaphor - a scale that only stays level when both sides are truly equal - carries a student from their very first equation through the hardest form they'll see in 8th grade.

  • The equality sign is a physical scale, not just a symbol. Both sides visibly tip based on their real numeric weight, so "equal" is something a student can see and feel before it's ever an abstract rule about balancing equations.
  • Four representations of the same idea, at once. The color-coded algebra tiles (blue = variable, orange = constant), the symbolic equation, a fully expanded term-by-term view, and - in Sandbox mode - a live substituted-value readout are all on screen together, so a student can connect the concrete, visual, and symbolic versions of the same relationship.
  • Four-tier progression matched to real grade-level standards. 1-Step (grade 6) → 2-Step (grade 7) → Variables on Both Sides → Complex/Distribution (grade 8), each with its own 15-level track, so a student only sees rule combinations they're actually ready for.
  • Sandbox mode for open-ended exploration. No win condition - freely add or remove variables and constants on either side and choose any value for x, to build intuition before being scored on it.
  • The distributive property, made visible. The Expand/Factor toggle actually animates between the grouped p(x + q) form and the fully expanded term list, instead of just stating the rule.
  • A guardrail against a common frustration point. Dividing when it would create a fraction pops a clear warning instead of silently producing a confusing result - and still lets a student proceed if that's what they intend.
  • Fraction-aware, not decimal-forced. The answer box accepts inputs like "5/2", so exact rational answers aren't mangled into decimals.
  • Wrong-answer hints tailored to the difficulty tier. Instead of one generic "try again," the hint text nudges toward the strategy that actually matters at that level - isolating a variable, clearing fractions, or expanding first.
  • Low-stakes practice. Unlimited undo, a full level reset, no accounts, and no permanent record of mistakes.
