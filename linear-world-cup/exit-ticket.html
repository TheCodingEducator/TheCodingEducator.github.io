Answer Key: Exit Ticket

Slope and y = mx + b
  1. b = 1, m = (−5 − 1) / 3 = −2 → y = −2x + 1
  2. m = 4, b = −2
  3. Yes. b = 0, so the line goes through the origin, and y is always 5 times x.

Quick read: y = −2x − 5 on #1 means the student used the goal's y-value as b; y = −(1/2)x + 1 means run over rise. Try Proportional mode on Easy with them.
