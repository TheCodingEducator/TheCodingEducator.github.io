Answer Key: Exit Ticket

The Pythagorean Theorem
  1. 20² + 15² = 400 + 225 = 625, √625 → c = 25
  2. 6² + h² = 10², h² = 100 − 36 = 64 → 8 ft
  3. 7² + 24² = 49 + 576 = 625 = 25² → Yes (the converse of the Pythagorean theorem).
