An equation is a balance: both sides are equal. Whatever you do to one side, do to the other. Use inverse operations to get x alone: undo adding by subtracting, and undo multiplying by dividing. Check your answer by substituting it back in.

Key vocabulary

  • equation: a statement that two expressions are equal, like 2x + 3 = 11
  • variable: a letter, like x, that stands for an unknown number
  • coefficient: the number multiplied by the variable; in 2x, the coefficient is 2
  • constant: a number on its own, without a variable
  • solution: the value of the variable that makes the equation true
  • inverse operations: operations that undo each other: add and subtract, multiply and divide
  • like terms: terms with the same variable part, like 3x and 5x, which can be combined
  • distributive property: a(b + c) = ab + ac, as in 2(x + 4) = 2x + 8

Answer Key: Solving Equations

For the teacher
  1. Subtract 3 from both sides → x = 5
  2. Add 4 to both sides → x = 13
  3. Divide both sides by 4 → x = 7
  4. Multiply both sides by 5 → x = 30
  5. 2x = 6 → x = 3
  6. 3x = 21 → x = 7
  7. 5x = 25 → x = 5
  8. x / 2 = 7 → x = 14
  9. Subtract x: 2x + 2 = 8, 2x = 6 → x = 3
  10. Subtract 2x: 3x − 4 = 11, 3x = 15 → x = 5
  11. Subtract 4x: 3x + 3 = 18, 3x = 15 → x = 5
  12. Subtract 2x: 4x = 20 → x = 5
  13. 2x + 2 = 4, 2x = 2 → x = 1 (or divide by 2 first: x + 1 = 2)
  14. 3x − 6 = 15, 3x = 21 → x = 7 (or x − 2 = 5)
  15. 4x + 12 = 2x + 20, 2x = 8 → x = 4
  16. 5x + 5 = 3x + 9, 2x = 4 → x = 2
  17. 30 + 10m = 15m, 30 = 5m → month 6 (both have cost $90)
  18. Riley only multiplied the x by 2, not the 4. Correct: 2x + 8 = 18, 2x = 10 → x = 5. Check: 2(5 + 4) = 18 ✓
