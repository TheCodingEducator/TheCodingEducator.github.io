Answer Key: Angle Relationships

For the teacher
  1. 90 − 34 = 56°
  2. 90 − 72 = 18°
  3. 180 − 118 = 62°
  4. 180 − 27 = 153°
  5. x is vertical to 40° → x = 40°; y is adjacent (supplementary) → y = 140°
  6. x = 115°; y = 65°
  7. ∠1 = 115°, ∠3 = 65°, ∠4 = 115°, ∠5 = 115°, ∠6 = 65°, ∠7 = 65°, ∠8 = 115°
  8. a) corresponding (equal)   b) alternate interior (equal)   c) co-interior / same-side interior (add to 180°)   d) vertical (equal)
  9. x + 2x = 90, 3x = 90 → x = 30; angles 30° and 60°
  10. 4x + 40 = 180, 4x = 140 → x = 35; angles 115° and 65°
  11. Dana subtracted from 180° (that's the supplement). Complementary angles add to 90°: 55°
