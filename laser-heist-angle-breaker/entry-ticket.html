A warm-up for the start of class, before students play or start the worksheet. It reviews adding angles and measuring them, using things students see every day, then asks them to think ahead to parallel lines. Two tickets print on each page; cut along the dashed line. The answer key prints on its own page after it.

4. Think ahead: a laser beam crosses two parallel lines. It makes a 60° angle with the first line. What angle do you think it makes with the second line? Why?

Answer Key: Entry Ticket

Before the Heist
  1. 180 − 32 = 148°
  2. 90 − 50 = 40°
  3. 140° (read the scale that starts at 0 on the angle's first side)
  4. Any reasoning counts. The answer students discover today: 60° again (corresponding angles), because the lines are parallel, so the beam crosses both the same way.

Quick read: 58° on #1 or 130° on #2 means the student mixed up 90 and 180. An answer of 40° on #3 means the student read the wrong scale. Use #4 to open the lesson, then test it in the Laser Heist.
